# HR Data Analysis Project

## Project Overview
This Power BI project focuses on analyzing HR data to gain insights into employee trends, attrition, performance, and other key HR metrics. The dashboard provides a comprehensive visualization of various HR factors, enabling data-driven decision-making for the HR team.

## Features & Insights
- **Employee Demographics:** Breakdown of employees by department, gender, age, and tenure.
- **Attrition Analysis:** Understanding employee turnover rates and identifying key reasons for attrition.
- **Performance Metrics:** Evaluation of employee performance based on different KPIs.
- **Salary Trends:** Salary distribution across different roles, departments, and experience levels.
- **Absenteeism & Attendance:** Tracking employee attendance patterns and identifying issues.
- **Hiring & Recruitment:** Insights into new hires, recruitment trends, and hiring effectiveness.

## Data Source
The dataset used in this Power BI report includes HR records with details such as:
- Employee ID
- Age, Gender, Department, and Job Role
- Salary and Benefits
- Performance Ratings
- Years of Experience
- Attrition Status

## Tools & Technologies Used
- **Power BI:** Used for data visualization and dashboard creation.
- **DAX (Data Analysis Expressions):** Used for advanced calculations and metrics.
- **Power Query:** Data transformation and preprocessing.
